# Supply Chain Resilience Command Center — Data Dictionary

## 1. Domain Overview & Principles

The Supply Chain Twin domain model is a normalized, typed, epistemic graph representing a multi-tier manufacturing supply chain.

### Core Data Integrity Rules:
1. **Stable Identifiers**: Every record carries an immutable string `id` (e.g., `fac-taoyuan-pack`, `shp-1002`).
2. **Epistemic Classification**: Every record or critical property carries an epistemic tag:
   - `OBSERVED`: Direct telemetry, ERP read, or physical sensor fix.
   - `INFERRED`: Derived via spatial geofencing or multi-hop dependency propagation.
   - `SIMULATED`: Generated by the recovery heuristics or scenario engine.
   - `UNKNOWN`: Missing commercial data that is preserved as explicitly unknown without synthetic certainty.
   - `STALE`: Data whose age exceeds the configured validity TTL.
3. **Nullability & Missing Data**: Unobserved fields are preserved as `null` or `'UNKNOWN'`. They are never filled with hallucinated defaults. Missing commercial data degrades the `dataConfidence` scoring component.

## 2. Entity Specifications

### 2.1 Facility (`Facility`)
Represents a physical site (factory, warehouse, port, assembly plant) in the network.

| Field | Type | Required | Description | Example / Allowed Values |
|---|---|---|---|---|
| `id` | `string` | Yes | Unique stable identifier | `"fac-taoyuan-pack"` |
| `name` | `string` | Yes | Human-readable name | `"Taoyuan Advanced Packaging"` |
| `type` | `string` | Yes | Site classification | `'supplier' \| 'manufacturing' \| 'warehouse' \| 'port'` |
| `latitude` | `number` | Yes | WGS84 Latitude [-90, +90] | `24.9936` |
| `longitude` | `number` | Yes | WGS84 Longitude [-180, +180] | `121.3010` |
| `country` | `string` | Yes | ISO 3166-1 alpha-2 / country name | `"TW"`, `"Taiwan"` |
| `criticality` | `string` | Yes | Site tier criticality | `'CRITICAL' \| 'HIGH' \| 'MEDIUM' \| 'LOW'` |
| `capacity` | `number` | No | Daily units throughput capacity | `12000` or `null` |
| `owner` | `string` | Yes | Operating entity | `"Taiwan Precision Packaging Corp"` |
| `source` | `string` | Yes | Provenance source system | `"SAP_ERP_TW_PROD"` |
| `observedAt` | `string` | Yes | ISO 8601 UTC timestamp | `"2026-10-18T06:00:00Z"` |
| `confidence` | `number` | Yes | Float in range [0.0, 1.0] | `0.94` |
| `epistemicStatus` | `string` | Yes | Classification badge | `'OBSERVED' \| 'INFERRED' \| 'SIMULATED' \| 'UNKNOWN' \| 'STALE'` |
